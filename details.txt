GIT WAY — COMMIT WATERMARK DETAILS
==================================

Watermark ab code se control hota hai. Jab chaho laga sakte ho, jab chaho hata sakte ho.
Koi app setting ya rebuild ke alawa kuch nahi — bas neeche di jagah text badlo aur APK build karo.

KYA KARNA HAI
-------------
File kholo:
    app/src/main/kotlin/com/io/git/way/domain/CommitMessageBuilder.kt

Usme ye line dhoondo:
    const val WATERMARK: String = ""

Watermark LAGANE ke liye quotes ke andar apna text likho, jaise:
    const val WATERMARK: String = "Made with Git Way"

Watermark HATANE ke liye wapas blank kar do:
    const val WATERMARK: String = ""

EXAMPLE OUTPUT
--------------
Agar commit message hai:
    Upload 5 file(s) to root
Aur WATERMARK me likha hai:
    Made with Git Way

Toh GitHub par commit aisa dikhega:
    Upload 5 file(s) to root

    Made with Git Way

Watermark hamesha commit message ke BODY me neeche judta hai.
Subject line (pehli line) waisi hi rehti hai.

KAHAN-KAHAN LAGEGA
------------------
Watermark centrally lagta hai, isliye ye sab commits me aayega:
- Upload / Sync flow
- File create / edit / rename / duplicate / delete
- Paste
- .gitignore update
- GitHub Actions workflow files add
- Naye repo ka "Initial commit"

AGAR WATERMARK BLANK HAI
------------------------
Koi extra line nahi judegi — commit message bilkul clean rahega.

NOTE
----
- Change karne ke baad APK dobara build/install karna padega.
- GitHub par jo purane commits already hain unka message change nahi hoga.
- Confirmation screen par "Will appear on GitHub as" preview me watermark dikh jayega.
