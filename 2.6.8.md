# Git Way 2.6.8 — What's New

**Version:** 2.6.8 (versionCode 218)

A polish-focused update: a fresh ASUS OS 3.0-inspired look, pull-to-refresh everywhere you need it, smoother animations, a compact Profile screen, and back navigation that finally behaves screen by screen.

---

## ✨ Highlights

- **ASUS OS 3.0-inspired theme** — refreshed light and dark palettes across the entire app, with consistent surfaces, borders and accent colors.
- **Pull-to-refresh** — pull down on the repository list or inside the file browser to reload fresh data from GitHub.
- **Screen-by-screen back navigation** — back now closes the current layer before leaving the screen, all the way through the upload flow.
- **Smoother feel** — animated screen transitions, card entrances and repository row animations make scrolling and navigation feel more natural.
- **Compact Profile** — reorganized sections and smaller controls for a cleaner, less cluttered Profile screen.

---

## 🆕 New

- Added pull-to-refresh to the **repository list**.
- Added pull-to-refresh to the **file tree**. Refreshing collapses every expanded folder, so the tree returns in a clean, fully collapsed state.
- Added slide + fade transitions when switching between screens.
- Added subtle fade, lift and scale entrance animations to cards and repository rows.
- Added top-bar back arrows to the sync flow: **Folder Selection → Changes → Confirm Upload → Uploading**.
- Added an optional, code-controlled commit watermark. It is **off by default**; commits stay clean unless a watermark is configured.

---

## 🛠️ Fixed

- **Back navigation is now layered correctly:**
  - File editor → file viewer → repository browser → repository list.
  - Search closes before leaving the screen.
  - File selection mode clears before leaving the screen.
  - Back during an upload cancels the upload instead of letting it run in the background.
  - Back from the completion screen returns directly to the repository list.
- **Tree guide lines** now stay perfectly aligned with indentation and file/folder icons while zooming.
- **Repository list refresh** no longer replaces the existing list with a loading skeleton. The current list stays visible while the refresh indicator runs.
- **Empty and error states** are now scrollable, so pull-to-refresh works even when there is nothing to show.
- **Cleaner commit messages** — automatic "Git Way" branding has been removed from generated commits.

---

## 🎨 UI & Polish

- Profile sections reordered into a clearer flow: Quick Actions, Accounts, Appearance, Security, Performance, Achievements, Connected Account, Developer, About and Danger Zone.
- Profile buttons and quick-action tiles made more compact.
- Consistent ASUS OS 3.0 colors in both light and dark mode.
- Improved press feedback on repository rows and icon buttons.

---

## 📝 Notes

- Minimum Android version: **8.0 (API 26)**.
- Target SDK: **36**.
- If you are upgrading from an older version, simply install this build over it — no data migration is required.
